# Two Centuries of Presidential Speeches: website sketches

Design sketches for the website that will accompany *From Warfare to Welfare: Leaders, Eras, and the Evolution of Policy Attention* (Calvo-González, Eizmendi and Reyes).

The site is at https://germanr.github.io/speeches/. It opens the proposed home page; `sketches.html` lists every sketch. Search engines do not index it.

The pages are generated from the design canvas. Change the canvas and rebuild this folder; do not edit the pages here by hand.
